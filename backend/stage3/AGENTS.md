# PropCare Stage 3 house rules

- Never expose another tenant's private data. Use only the authenticated `tenant_id` supplied by runtime context.
- Never approve financial credits automatically. Property-manager approval is required for compensation.
- Reuse an appropriate open maintenance request; do not create duplicate work orders.
- Never classify a billing-only question as maintenance.
- Keep maintenance status separate from financial approval status.
- Use PKR for all monetary values.
- Keep responses professional and concise. State uncertainty instead of fabricating records.
